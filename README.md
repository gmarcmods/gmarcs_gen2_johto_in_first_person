# gmarcs_gen2_johto_in_first_person

First-person companion for gmarcs_gen2_voxel_mod.

Adds interiors with ceilings, textured cave roofs and rock, forest canopy,
native grass, birds, skies, horizon, weather and ambient sound. Does not
include a voxel renderer or ROM data. Requires gmarcs_gen2_voxel_mod.

Inspired by Kanto in First Person (unmaintained), original by mrmushrooms11:
https://github.com/mrmushrooms11/kanto-first-person

## Install

Import both zips via the launcher MODS tab. Enable both. Use Gold, Silver or
Crystal. Choose VOXEL -> 1ST or 3RD in options (or cycle with 3).
